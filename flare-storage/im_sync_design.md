# IM 初始化同步设计方案（工业级）

## 一、目标

实现一个支持： - 不丢消息 - 多端一致 - 可续传 - 幂等处理

的 IM 初始化同步机制。

------------------------------------------------------------------------

## 二、核心原则

1.  **seq 连续**
2.  **事件完整（message + delete + update）**
3.  **支持断线续传**
4.  **客户端幂等**

------------------------------------------------------------------------

## 三、整体架构

    客户端
       ↓
    Snapshot（快照）
       ↓
    Event Log（事件流）
       ↓
    ACK 确认

------------------------------------------------------------------------

## 四、初始化流程

### 1. 客户端请求

    GET /sync/init

------------------------------------------------------------------------

### 2. 服务端返回 Snapshot

``` json
{
  "conversations": [],
  "messages": [],
  "snapshotSeq": 10000
}
```

说明： - 只包含当前状态 - 不包含已删除消息

------------------------------------------------------------------------

### 3. 拉取增量事件

    GET /sync/events?fromSeq=10000

返回：

``` json
[
  { "seq": 10001, "type": "msg" },
  { "seq": 10002, "type": "delete" },
  { "seq": 10003, "type": "msg" }
]
```

------------------------------------------------------------------------

## 五、客户端处理

### 1. 应用快照

``` ts
applySnapshot(data)
```

------------------------------------------------------------------------

### 2. 回放事件

``` ts
applyEvent(event)
```

------------------------------------------------------------------------

### 3. 更新 seq

``` ts
lastSeq = event.seq
```

------------------------------------------------------------------------

### 4. ACK

    ack(lastSeq)

------------------------------------------------------------------------

## 六、删除设计

删除必须作为事件存在：

``` json
{
  "seq": 10002,
  "type": "delete",
  "msgId": "xxx"
}
```

说明： - 不可物理删除 - 必须占用 seq

------------------------------------------------------------------------

## 七、断线重连

客户端：

    GET /sync?fromSeq=lastSeq

------------------------------------------------------------------------

服务端：

-   返回后续事件
-   若 seq 过期 → 返回错误，重新 snapshot

------------------------------------------------------------------------

## 八、幂等设计

客户端必须保证：

``` ts
if (event.seq <= lastSeq) return
```

------------------------------------------------------------------------

## 九、服务端存储

### Message 表

-   msg_id
-   seq
-   content
-   status（normal / deleted）

------------------------------------------------------------------------

### Event 表

-   seq
-   type
-   target_id

------------------------------------------------------------------------

## 十、一句话总结

> 初始化同步 = 快照恢复 + 事件回放
